Acidica
=======

An implementation of [Vintage BASIC], just for fun.

[Vintage BASIC]: http://www.vintage-basic.net/

The name started as "acidic" because chemically, acidic is the opposite of
basic. Then I noticed it was almost a palindrome so I added the final "a". This
also made it sound like science fiction.

More about the motivation and development is in [my blog post about
Acidica][blog].

[blog]: https://nedbatchelder.com/blog/202607/acidica
